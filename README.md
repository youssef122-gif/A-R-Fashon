## 📥 طريقة تحميل الـ EXE

### الخطوة 1 - رفع الملفات على GitHub
1. روح على [github.com](https://github.com) وسجّل دخول (أو أنشئ حساب مجاناً)
2. اضغط **New repository** (الزرار الأخضر)
3. اكتب اسم للمشروع مثلاً: `fawateer-app`
4. اضغط **Create repository**

### الخطوة 2 - رفع الملفات
1. في الصفحة الجديدة، اضغط **uploading an existing file**
2. ارفع كل محتوى مجلد `fawateer-app` (اختار كل الملفات والمجلدات)
3. اضغط **Commit changes**

### الخطوة 3 - تشغيل البناء
1. بعد الرفع، اضغط على تبويب **Actions** في الأعلى
2. هتلاقي workflow اسمه **Build Windows EXE**
3. اضغط عليه، ثم اضغط **Run workflow** ← **Run workflow**
4. ⏳ انتظر 3-5 دقائق

### الخطوة 4 - تحميل الـ EXE
1. لما يخلص، اضغط على الـ run اللي اتعمل
2. تحت **Artifacts** هتلاقي: **فواتيرك-الكرتوني-Setup**
3. اضغط عليه ← هيتحمل ملف ZIP فيه الـ **Setup.exe** 🎉
4. فك الـ ZIP وشغّل الـ Setup.exe
